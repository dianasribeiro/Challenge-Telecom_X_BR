Análise de Churn em Empresa de Telecomunicações

Este projeto tem como objetivo principal analisar o churn de clientes de uma empresa de telecomunicações.
A análise de churn, ou evasão de clientes, é crucial para que a empresa possa identificar os fatores que levam os clientes a cancelarem seus serviços e, a partir daí, desenvolver estratégias para retê-los.

Motivação
O churn representa uma perda significativa de receita para qualquer negócio. 
Compreender o porquê de os clientes estarem saindo é o primeiro passo para criar planos de ação que melhorem a satisfação e fidelidade do cliente. Este projeto busca responder a perguntas-chave, como:

Quais características dos clientes estão mais associadas ao churn?

Existem padrões de comportamento de uso que indicam uma alta probabilidade de churn?

Quais serviços oferecidos pela empresa têm maior ou menor impacto na decisão de churn?

Metodologia
A análise de dados foi conduzida em várias etapas:

Limpeza e Pré-processamento dos Dados: tratamento de valores ausentes, conversão de tipos de dados e padronização das colunas.

Análise Exploratória de Dados (EDA): visualizações e estatísticas descritivas para entender a distribuição das variáveis e a relação entre elas.

Análise de Churn: investigação dos fatores que contribuem para o churn, incluindo características demográficas, serviços contratados e tempo de relacionamento com a empresa.


Tecnologias e Ferramentas
Linguagem de Programação: Python

Bibliotecas:

Pandas: manipulação e análise de dados.

Numpy: operações numéricas.

Matplotlib e Seaborn: visualização de dados.

Ambiente de Desenvolvimento: Jupyter Notebook
